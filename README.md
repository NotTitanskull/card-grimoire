# Card Grimoire

A card collection manager built with Vue and JavaScript.

## Project status

Early development.

## Requirements

- Node.js 22.18 or later within version 22, or Node.js 24.12 or later.
- npm.

## Development

Install dependencies:

```sh
npm install
```

Start the development server:

```sh
npm run dev
```

## Production build

Build the application:

```sh
npm run build
```

Preview the production build locally:

```sh
npm run preview
```
